# Bizdin Taxi — Android shortcut app

Бұл шағын Android қосымша телефондағы Bizdin Taxi белгісін басқанда Telegram-дағы
https://t.me/AshysaiTaxiBot ботын ашуға арналған. Боттың өз кодын және дерекқорын өзгертпейді.

## APK құрастырудың ең оңай жолы
1. Осы ZIP архивін GitHub-та жаңа репозиторийге жүктеңіз.
2. Репозиторийдің Actions бөліміне кіріңіз.
3. `Build Bizdin Taxi APK` workflow-ін таңдаңыз.
4. `Run workflow` басыңыз.
5. Құрастыру біткен соң `Bizdin-Taxi-APK` артефактын жүктеңіз.
6. Архив ішіндегі `app-debug.apk` файлын Android телефонына көшіріп, орнатыңыз.

Ескерту: бұл — ботты ашатын жеңіл қосымша. Такси тапсырыстары мен тарифтер Telegram боттың ішінде бұрынғыдай орындалады.
